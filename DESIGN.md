# Stakl design

Local developer workstation. Neutral navigation rail and work surface, flat application and profile rows, green operational actions, semantic text-and-dot statuses, and tabular runtime data. Locally bundled IBM Plex Sans for the interface and IBM Plex Mono for commands, paths, PIDs, ports, and logs. Dark mode uses graphite surfaces; light mode uses mineral grays. Applications, Ports, Activity, Configuration, and System are the main destinations. Controller connection and theme controls live in the utility bar; search, counts, filters, and favorites live above the application ledger. Profiles sit above organizational groups. Navigation becomes a drawer on small screens; application details retain full-width readable logs. Clear empty/error/loading states and visible keyboard focus are mandatory. No invented applications or metrics.

See [the UI design system](docs/ui-design-system.md) for tokens and interaction patterns, and [the README](README.md) for current UI screenshots.
