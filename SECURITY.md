# Security Policy

## Supported versions

Security fixes are made against the latest released version. Upgrade to the latest release before reporting a problem that may already be fixed.

## Reporting a vulnerability

Use GitHub's private **Report a vulnerability** form for this repository. Do not open a public issue for an undisclosed vulnerability and do not include real credentials, tokens, logs, or configuration secrets in a report.

Include the affected version and platform, impact, reproduction steps, and any suggested mitigation. You may disclose the issue publicly after a fix is available or after coordinating disclosure with the maintainer.
